The Orchid Hour is a one-screen stealth heist. Cross a moonlit conservatory, read the keeper cones and glass eyes, steal the Sun Orchid from its bell jar, then carry it back to the van before the getaway clock runs out. Teal shadow slows detection, crates block sight, and both tools add alarm.

## Run it

```sh
node serve.ts
```

Open http://localhost:8080 in a desktop browser. Move with WASD or the arrow keys, crouch with Shift, throw chalk with D at the pointer, drop a veil with V, take the orchid with E, restart with R and open help with H.

To build the hand-in files locally:

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts
```
